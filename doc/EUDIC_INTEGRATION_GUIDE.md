# 🚀 欧路生词本集成与更新指南 (V3.x)

本文档记录了 YoudaoTranslator 在集成“欧路生词本”功能过程中的更新细节、问题排查记录（踩坑指南）以及最终的配置教程。

## 🌟 一、本次更新概览

1. **新增：欧路生词本同步**
   - 实现了无缝将查询的单词同步到欧路词典的生词本中。
   - 底层脱离对 Node.js 的强依赖，完全使用项目内置的 txiki (轻量级 JS 运行时) 与 redaxios 发送网络请求。
2. **修复：添加单词的内容错误**
   - 修复了此前“按快捷键添加生词时，将中文翻译（如`你好`）而非英文原词（如`hi`）存入生词本”的逻辑漏洞。目前已强制映射传递 `r.pronounce` (英文原词)。
3. **修复：快捷键与发音冲突**
   - 彻底解决了添加单词时，系统错误调用 macOS `say` 或 `afplay` 命令导致的发音报错问题。
   - 重新规范了操作修饰键，避免快捷键组合触发引起的流程双重执行。

## 🕳️ 二、开发踩坑记录 (Pitfalls)

在 Workflow 的底层代码与 Alfred 图形界面的结合中，我们遇到了以下几个典型的“坑”：

### 1. 组合快捷键导致的分支“双重触发”
- **现象**：将添加到生词本的快捷键在 Alfred 中设为 `Cmd + Shift` 时，每次添加单词不仅加入了生词本，还会同时触发“本地发音”。
- **原因**：Alfred 的 `Script Filter` 机制对修饰键的判断是叠加的。当按下 `Cmd` + `Shift` + 回车时，Alfred 会认为既满足了 `Cmd` 分支（本地发音），又满足了 `Cmd+Shift` 分支（生词本），结果放行了两条工作流。
- **解法**：在代码层面 (`item.ts` / `workflow.ts`) 强制分离修饰键，不再使用复合按键。现规定 `Cmd` 专职发音，`Ctrl` 专职添加生词。

### 2. 标准输出 (stdout) 被管道误传引起的诡异报错
- **现象**：添加生词功能本身有效，但每次添加后，macOS 系统竟然会把“添加到欧路生词本成功”这句话用英文语音强行读出来；稍作修改后甚至引发了 `Error: AudioFileOpen failed (-43)` 报错。
- **原因**：Alfred 的节点连线本质上是管道传输（Pipeline）。我们在查词节点的后面，将“添加生词操作(Run Script)”输出节点错误地接入了“发音(Run Script)”节点。这导致 `add_word.js` 文件脚本里的 `console.log("添加成功")` 字符串直接交给了系统语音 `say` 命令去执行。
- **解法**：去掉代码里添加单词动作的 `console.log()`，并**在 Alfred 界面中断开生词本与发音节点的连线**。所有的通知回归到 Alfred 的 `Post Notification` 模块处理。

## 🛠️ 三、安装与配置教程

完成代码构建后，请按照以下步骤在 Alfred 中完成配置。

### 1. 更新 Workflow 核心文件
1. 运行 `npm run build` 生成最新的 `dist` 目录。
2. 将 `dist` 目录下的所有文件以及整个目录覆盖或拷贝到你 Alfred Workflow 实际所在的内部目录中。

### 2. 配置欧路词典 Token 环境变量
为了能将单词推送到你私人的生词本，需要配置授权：
1. 在 Alfred 中打开 `YoudaoTranslator` 工作流。
2. 点击右上角的 `[x]` (Environment Variables 环境变量设置)。
3. 添加一个名为 `eudic_token` 的变量。
4. 将你从欧路词典网页版抓取到的授权 Token（通常在请求头的 `Authorization` 字段，格式类似于 `NIS ...`）填入。**注：如果不填，功能自动跳过且不报错。**

### 3. 正确的节点连线（关键）
请检查 Alfred 面板中的连线逻辑，确保：
- `Script Filter` 节点引出，双击圆圈勾选 **`Command(⌘)`**，连接 => **本地发音 (Run Script, `say`)**
- `Script Filter` 节点引出，双击圆圈勾选 **`Option(⌥)`**，连接 => **在线发音 (Run Script, `afplay`)**
- `Script Filter` 节点引出，双击圆圈勾选 **`Control(⌃)`**，连接 => **添加生词 (Run Script, `./runtime/txiki dist/add_word.js "{query}"`)**

**⚠️ 警告：** 
请绝对**不要**将“添加生词”节点的输出端连入任何“发音”节点。添加生词节点的右端只能不连，或者连接到绿色的 `Post Notification` 用于弹窗提示即可。
